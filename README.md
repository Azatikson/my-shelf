# Моя Полка

Личный трекер книг в браузере. Тёмная тема, поиск через Open Library API, оценки, заметки и цели на год. Работает без сервера, без регистрации, без ключей API.

## Возможности

- Поиск книг через Open Library API по названию, автору или жанру
- Полки: "В планах", "Читаю", "Прочитано", "Брошено"
- Оценка книг по 10-балльной шкале
- Личные заметки «о чём эта книга»
- Прогресс чтения по страницам с процентной шкалой
- Метки для книг (свои теги, не из API)
- Фильтры по статусу и сортировка по дате, оценке, названию, автору
- Поиск по названию, автору, заметкам и меткам
- Статистика: сколько прочитано, средняя оценка, топ жанров
- Цель на год с прогресс-баром
- Рекомендации на основе твоих жанров
- Экспорт и импорт JSON
- Экспорт в Markdown для Obsidian или Notion
- Тёмная и светлая темы с автосохранением выбора
- Все данные хранятся в localStorage - ничего не уходит на сервер

## Технологии

- HTML5
- CSS3 (переменные, тёмная и светлая темы)
- JavaScript (без фреймворков и сборки)
- Open Library API как источник данных о книгах
- localStorage для хранения полки

## Запуск

1. Склонируйте репозиторий:
   git clone https://github.com/azatikson/moya-polka.git

Никаких зависимостей, сборки и настройки. Проект работает из коробки.

## Зачем этот проект

Я читаю много книг по продакт-менеджменту и постоянно сталкивался с одной проблемой: через месяц я помню, что читал книгу, но не помню, о чём она. Открывать заметки в разных приложениях неудобно, а держать всё в голове невозможно.

Моя Полка решает три задачи:

1. Быстро находить книги и складывать их на полку по статусу
2. Записывать краткую выжимку своими словами, чтобы через год вспомнить суть
3. Видеть прогресс: сколько прочитано, средняя оценка, топ жанров

Это личный инструмент, которым я пользуюсь каждый день. Поэтому все решения в проекте продиктованы реальным сценарием использования, а не абстрактными требованиями.

## Продуктовые решения

Почему именно такой набор фич и такой интерфейс:

- **Поле "о чём эта книга" как ключевая фича.** Оценки и статусы это стандарт для любого трекера. Но главное, что я хотел получить, это короткая выжимка своими словами. Через полгода именно она помогает вспомнить книгу, а не звёздочки или обложка
- **Метки поверх жанров.** Жанры приходят из Open Library и часто не отражают мою логику. Метки «#PM», «#psychology», «#2025» описывают книги так, как я о них думаю. Это принципиально разные вещи
- **Отдельные статусы "В планах" и "Брошено".** Многие трекеры знают только «читаю» и «прочитано». Но «хочу прочитать» и «бросил» это тоже важные состояния. Первое помогает формировать очередь чтения, второе честно показывает, что не зашло
- **Мгновенный поиск по заметкам.** Смысл заметок в том, чтобы их находить. Если бы поиск работал только по названию, заметки бы терялись. Поэтому поиск ищет по названию, автору, заметке и меткам одновременно
- **Экспорт в Markdown.** Заметки живут не в вакууме. Я веду второй мозг в Obsidian, поэтому экспорт в `.md` это не «дополнительная фича», а необходимость для моего сценария
- **Тёмная тема по умолчанию.** Читаю и работаю вечером. Светлая тема остаётся для дневного использования и презентаций
- **localStorage вместо сервера.** Продукт должен работать у любого, кто скачал репозиторий, без регистрации и без ключей API. Для личного трекера сервер не нужен

## Метрики продукта

Как я оцениваю успех этого инструмента:

- **Количество книг на полке.** Базовая метрика, но сама по себе мало значит. Важно следующее
- **Доля книг со статусом «Прочитано».** Если из 30 книг прочитано 3, продукт не помог довести чтение до конца
- **Доля книг с заполненной заметкой.** Ключевая метрика. Если заметок нет, я не получу пользы через год. Цель: заметка у каждой прочитанной книги
- **Возвраты к заметкам.** Сколько раз я открывал заметку, чтобы что-то вспомнить. Это главный показатель реальной пользы
- **Прогресс к цели на год.** Цель это не сама цель, а инструмент мотивации. Если прогресс идёт, продукт работает
- **Экспорт в Markdown.** Использую ли я экспорт, чтобы переносить заметки в Obsidian. Если нет, значит, интеграция не нужна
